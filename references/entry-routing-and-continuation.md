# 任意阶段接入与持续推进

## 目的

用户可能从 Brief、客户答疑、研究结论、策略草稿、Big Idea、具体物料、媒介、方案 Markdown 或 PPT 生产中的任何位置进入。先确定用户最终要得到什么，再找到决定该产出是否成立的最近必要上游。

“回到必要上游”是为了补足判断，不是为了强迫用户重跑整条流程。

## 先建立本轮产出契约

开始前在 `00-项目输入与上下文.md` 记录：

- 当前入口；
- 最终产出；
- 完整链路或单模块；
- 已有且可继承的判断；
- 必需模块；
- 明确不需要的模块；
- 当前最小信息缺口；
- AI 推荐的默认推进路径；
- 下一个真正需要人工判断的位置。

已有外部材料不以文件名判断是否有效。只要内容足以承担相应判断、来源清楚并经用户确认，就可以作为等价输入。

## 判断最近必要上游

| 用户想得到的产出 | 最近必要上游 | 不成立时回到哪里 |
|---|---|---|
| Brief 研究与客户问题 | 第一轮深度研究 | Brief 对象、市场或授权范围 |
| 生意策略 | 答疑后补研与真实问题重构 | 客户答疑、必要研究 |
| Big Idea | 已选策略 | 第二轮策略 |
| Campaign 或多个创意物料 | 已选策略 + 创意基础 | 完整创意阶段，或最小创意基础 |
| KV 概念 | Campaign 表达宪法中的 KV 任务 | 最小创意基础或 Campaign 安排 |
| TVC 方向/脚本 | Campaign 表达宪法中的影片任务 | 最小创意基础或 Campaign 安排 |
| 事件方向 | Campaign 表达宪法中的事件任务 | 最小创意基础或 Campaign 安排 |
| 其他创意任务 | Campaign 表达宪法中的该任务 | 最小创意基础或 Campaign 安排 |
| 媒介/Roadmap | 已确认的策略、传播任务、资源和限制 | 策略或 Campaign 安排 |
| 方案脉络 | 已确认的必要上游模块 | 最早缺失的关键判断 |
| 逐页 Markdown | 已确认方案脉络 | 方案结构 |
| PPT/PDF视觉生产 | 已确认逐页 Markdown | 逐页内容 |

## 从 Brief 进入

用户提交可识别 Brief 且希望完成研究、策略或完整方案时，进入第一轮深度研究。研究范围由最终产出和不确定性决定，不先提交一份研究计划等待批准。

同一轮完成 `00`—`06`，然后等待客户答疑。完整链路只是在这里自然暂停，不等于任务已经完成。

如果用户提交 Brief 但只需要一个中途模块，先判断已有材料是否已经提供该模块所需的等价上游。足够时直接复用；不足时只补最近必要上游，不因材料形式是 Brief 就机械从第一阶段重跑。

## 从客户答疑进入

已有 `06` 或等价第一阶段成果，再收到客户回答、答疑会记录、用户纠偏或内部资料时：

1. 用 `07` 校准理解；
2. 用 `08` 补齐缺失研究，或在研究已经充分时深化洞察；
3. 进入真实问题重构与策略假设。

第二轮研究方向可以允许用户补充，但不把它变成默认审批点。

## 从策略进入

先检查现有材料能否说明：

- 需要促成的结果；
- 关键角色、时刻与行为；
- 当前阻力、机会或矛盾；
- 品牌可改变、绕过或重构什么；
- 策略怎样传导到结果；
- 支持、反证、风险和现实限制。

足够时复述 AI 的理解与推荐推进路径。用户确认或说“继续”后，可把它作为 `12` 的等价输入。只有一句口号、一个传播主题或模糊方向时，回第二轮策略工作台，不用创意替策略填洞。

## 从 Big Idea 或创意进入

先检查策略是否成立。策略足够时，再判断用户提供的创意是否已经包含最小创意基础：

- 人的真实处境；
- 希望发生的变化；
- 品牌回答；
- 品牌与产品证明；
- 不能被后续改写的边界。

已经足够：精炼并记录为 `16` 的等价输入，进入 Campaign 表达宪法。

仍然缺少核心创意判断：

- 用户希望探索 Big Idea：进入完整创意阶段；
- 用户不需要专门创意共创，只想完成物料：进入 Campaign 环节补齐最小创意基础，然后继续物料。

“跳过完整创意阶段”不等于跳过决定物料是否成立的创意基础。

## 从 KV、TVC、事件或其他物料进入

直接创作前先确认五件事：

1. 这个物料影响谁；
2. 它要促成什么变化；
3. 品牌在其中给出什么回答；
4. 它独自承担什么任务；
5. 哪些策略、创意、产品和现实边界不能被改写。

信息已经充分时只做精炼复述，不重复策略或 Big Idea 共创。信息不足时，根据用户最终目标选择：

- 需要完整创意探索：回第三阶段；
- 不需要完整创意探索：在 Campaign 环节补最小创意基础；
- 策略本身不成立：回第二轮策略。

KV、TVC、事件和扩展创意模块只处理自己的专业问题，不在模块内部偷偷重写上游。

## 从媒介进入

媒介不要求所有创意文件存在。只要能够说明：

- 最终生意或传播结果；
- 关键人群与行为；
- 已确定的传播任务；
- 必须承接的内容资产；
- 客户固定锚点、预算、资源、时间和限制；
- 哪些事项已经确定，哪些仍然开放。

就可以进入媒介与 Roadmap。

如果项目明确不需要创意，创意模块标记为 `not_required`。如果媒介依赖尚未明确的核心内容或品牌动作，回 Campaign 安排，而不是要求补齐全部创意编号。

## 从方案、逐页 Markdown 或 PPT 进入

### 方案脉络

先判断是否已有足以支撑说服链的策略、创意、媒介或其他必要结论。只补会让章节逻辑产生根本差异的缺口。

### 逐页 Markdown

已有方案脉络时继续逐页内容。用户提供的外部 Markdown 如果页码连续、每页只包含实际内容、没有悬空占位符并已得到确认，可以作为 `34` 的等价输入。

### PPT/PDF视觉生产

内容仍是长文、大纲或未确认草稿时，回逐页内容。内容已确认时进入 PPT 生产路线：比较高视觉生图与稳定 HTML/PDF，先做两张代表性样页，再生产整套。

## AI 默认推进

每次存在多个合理下游时，AI先给出推荐：

> 基于当前目标和已有材料，我建议下一步进入____，因为____。如果你没有异议，我会按这个路径继续。

用户说“继续”“按你的建议做”或表达同意时，视为接受推荐。用户已经明确要求“完整做完”“按你的判断推进”时，可视为预先接受不改变核心方向的可逆中间推荐，并在相应确认文件记录采用方式。只有没有清楚推荐、用户意见相互矛盾，或不同选择会改变项目核心方向时，才继续追问；预先授权不能越过客户答疑、核心策略或创意母体选择、逐页整体放行、视觉样页确认及不可逆授权。

用户否定当前策略、创意或执行方向并要求继续想时，不把它识别成新的文件生产任务。保持现有工作区不动，在聊天中理解否定原因、发展新方向并继续共创；只有用户明确确认新的结论并要求整理进文件或按此继续，才重新进入文件路由并一次性更新。

## 恢复已有项目

恢复时优先读取 `00` 的状态摘要和当前阶段的确认文件，再检查真实内容：

- 文件存在不等于已经确认；
- 文件不存在不等于内容一定缺失；
- 圆桌进行中时优先恢复圆桌；
- 新证据推翻上游时回到最早受影响处；
- 完整链路在阶段确认后继续前进，直到最终产出；
- 单模块达到声明产出后停止，不擅自扩大范围。

## 不要制造的阻塞

以下事项通常不需要暂停：

- 建立项目文件夹和 `00`；
- 第一轮研究范围；
- 第二轮常规补研方向；
- 可逆的模块顺序；
- 研究资料数量；
- AI已经能够给出明确推荐的选择；
- 明确不需要的模块缺少文件。

真正需要暂停的是客户专属信息、核心策略或创意方向选择、无法由推荐消解的重大 Campaign / 专业 / 媒介分歧、不可逆授权、PPT 工具或格式条件未知、整体逐页放行和视觉样页确认。方案结构只有会改变内容取舍、客户决策或核心说服逻辑时才暂停。
